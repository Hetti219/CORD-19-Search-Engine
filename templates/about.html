About This Search Engine

Overview

This search engine was developed as part of the 6CS030 Big Data assessment. It enables efficient retrieval of COVID-19 research papers from the CORD-19 dataset using the BM25 ranking algorithm.

Technology Stack

  • Search Library: Whoosh (Pure Python search library)
  • Web Framework: Flask
  • Data Processing: Pandas
  • Ranking Algorithm: BM25F
  • Dataset: CORD-19

How BM25 Ranking Works

BM25 (Best Matching 25) is a probabilistic ranking function that scores documents based on:

  • Term Frequency: How often query terms appear in the document
  • Document Length: Normalises scores so longer documents don't have an unfair advantage
  • Inverse Document Frequency: Rare terms are weighted more heavily than common terms

Dataset Information

The CORD-19 (COVID-19 Open Research Dataset) is a resource of scientific papers about COVID-19 and related coronaviruses. It was created by the Allen Institute for AI in partnership with leading research groups.

Information Needs Supported

  • Researchers: Finding papers on specific COVID-19 topics
  • Healthcare Professionals: Treatment protocols, clinical trial results
  • Policy Makers: Epidemiological data, transmission studies
  • Students: Literature review, background research
