Setup Required

The search index has not been created yet. Please follow these steps to set up the search engine:

Step 1: Download CORD-19 Dataset

Download the metadata.csv file from one of these sources:

  • Allen Institute for AI
  • Kaggle CORD-19 Dataset

Place the metadata.csv file in: data/raw/metadata.csv

Step 2: Install Dependencies

pip install -r requirements.txt

Step 3: Preprocess the Data

Run the preprocessor to clean and prepare the data:

python src/preprocessor.py

This will create data/processed/papers.csv

Step 4: Build the Search Index

Create the Whoosh search index:

python src/indexer.py

This will create the index in the index/ directory

Step 5: Restart the Application

Once the index is built, restart the Flask application:

python src/app.py

Then refresh this page.

Note:

Building the index may take several minutes depending on the dataset size. For faster testing during development, you can modify src/preprocessor.py to use a smaller sample (e.g., 10,000 papers).
